\chapter{Designations and Abbreviations}
\begin{SingleSpace}

Following designations and abbreviations are used in this work:\par\bigskip

\begin{description}[style=multiline,leftmargin=3.2cm,labelwidth=3.2cm]

  \item[RDBMS]   Relational Database Management System
  \item[SQL]     Structured Query Language
  \item[NoSQL]   Not Only SQL
  \item[ACID]    Atomicity, Consistency, Isolation, Durability
  \item[WAL]     Write-Ahead Log
  \item[LSM]     Log-Structured Merge-Tree
  \item[SIMD]    Single Instruction, Multiple Data
  \item[TPC-H]   Transaction Processing Performance Council Benchmark H
  \item[HTAP]    Hybrid Transactional/Analytical Processing
  \item[OLTP]    Online Transaction Processing
  \item[OLAP]    Online Analytical Processing
  \item[CAP]     Consistency, Availability, Partition Tolerance
  \item[AST]     Abstract Syntax Tree
  \item[ORM]     Object-Relational Mapping
  \item[API]     Application Programming Interface
  \item[TCP]     Transmission Control Protocol
  \item[NVMe]    Non-Volatile Memory Express
  \item[SSD]     Solid-State Drive
  \item[DDL]     Data Definition Language
  \item[DML]     Data Manipulation Language
  \item[PK]      Primary Key
  \item[FK]      Foreign Key
  \item[GC]      Garbage Collection
  \item[JVM]     Java Virtual Machine
  \item[CLI]     Command-Line Interface
  \item[JDBC]    Java Database Connectivity
  \item[IEEE]    Institute of Electrical and Electronics Engineers

\end{description}
\end{SingleSpace}
