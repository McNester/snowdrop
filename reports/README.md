# Reports Directory

This directory is the home for generated test and benchmark artifacts.

## Main Artifacts

- `test-report.md`
  - unified human-facing report generated by `snowdrop-testkit`
- `raw/snowdrop-testkit-results.json`
  - machine-readable raw output generated by `snowdrop-testkit`
- `tap/*.tap`
  - TAP-like smoke outputs generated from `tests/tap/`

## Optional Benchmark Artifacts

`tpch-bench` can also write raw benchmark JSON wherever you choose. The recommended location is:

- `reports/benchmarks/tpch-results.json`

Example:

```powershell
$env:PGPASSWORD = "<your-postgres-password>"
cargo run --release -p tpch-bench -- --scale 1 --runs 10 --with-indexes --seed 42 --output reports/benchmarks/tpch-results.json
```

## Notes

- `docs/` should contain stable documentation and guides.
- `reports/` should contain generated output and committed report snapshots when the team intentionally wants them in the repository history.
