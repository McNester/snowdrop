\chapter{Abstract}
\begin{SingleSpace}

Modern data-intensive applications increasingly require both transactional consistency and analytical performance from their database systems. Traditional relational database management systems (RDBMS) such as PostgreSQL provide robust ACID guarantees and a mature SQL ecosystem, but their monolithic architectures struggle to deliver sub-millisecond analytical query performance at scale. Conversely, NoSQL systems offer specialized performance advantages but sacrifice SQL compatibility and transactional guarantees, forcing developers into difficult trade-offs.

This diploma project presents Snowdrop, a proof-of-concept database engine that addresses this tension through a hybrid architecture while preserving PostgreSQL wire compatibility and a practical, migration-oriented SQL subset. Snowdrop exposes the PostgreSQL wire protocol, allowing existing PostgreSQL clients, ORMs, and CLI tools to connect without modification. Internally, it decomposes the responsibilities of a traditional database engine across three specialized components: Neo4j for schema metadata, embedded RocksDB for durable row-oriented data and secondary indexes, and an in-memory columnar cache with SIMD-accelerated filtering for analytical read performance.

The system implements ACID-style durability guarantees through a Write-Ahead Log that coordinates writes across the metadata and storage layers, ensuring crash recovery at any point in the write sequence. A Rust-based orchestrator manages SQL parsing, query planning, transaction coordination, migration workflows, and result assembly, leveraging Rust's zero-cost abstractions and absence of garbage collection to achieve deterministic tail latency.

Benchmarking against PostgreSQL~16 using the TPC-H benchmark at scale factor~1 demonstrates that Snowdrop achieves 0.8\,ms warm-cache latency on TPC-H Q6 (a date-range scan with aggregation over 6~million rows), compared to 1.5\,ms for PostgreSQL on identical hardware. The current implementation has also progressed beyond the original prototype milestones to include broader query compatibility, schema-fidelity features, and an automated PostgreSQL migration workflow consisting of preflight analysis, safe translation preview, table-by-table loading, and verification.

\bigskip
\noindent\textbf{Keywords:} hybrid database architecture, SQL compatibility, NoSQL, RocksDB, Neo4j, columnar storage, SIMD filtering, ACID, Write-Ahead Log, Rust, PostgreSQL wire protocol, TPC-H benchmark

\end{SingleSpace}
